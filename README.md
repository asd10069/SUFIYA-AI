# 👑 SUFIA AI TRADING BOT (TARIK)

আপনার দেওয়া স্ক্রিনশটের হুবহু ডার্ক পার্পল সাইবারপাঙ্ক ডিজাইনে তৈরি সম্পূর্ণ কার্যকরী **SUFIA AI Trading Bot**। এতে সমস্ত বাটন, ভয়েস কথা বলা ও শোনা, লাইভ সিগন্যাল এবং অটো ট্রেড ইঞ্জিন ১০০% কাজ করে।

---

## ✨ মূল ফিচারসমূহ (Key Features):

1. **🎙️ Voice Studio (সম্পূর্ণ কার্যকরী ভয়েস অ্যাসিস্ট্যান্ট)**:
   - ব্রাউজারের মাইক্রোফোন দিয়ে বাংলা ও ইংরেজি ভয়েস শোনে (Web Speech API)।
   - সোফিয়া মুখের কথায় তাৎক্ষণিক ট্রেডিং স্ট্র্যাটেজি ও সিগন্যাল বিশ্লেষণ করে উত্তর দেয়।
   - স্পিচ সিন্থেসিস (TTS) দিয়ে মানুষের মতো স্পষ্ট ভয়েসে কথা বলে উত্তর শোনায়।
   - সাউন্ড ওয়েভ ভিজ্যুয়ালাইজার কণ্ঠস্বরের সাথে সাথে অ্যানিমেট হয়।

2. **📊 Auto Trade Place (অটো ট্রেডিং ইঞ্জিন)**:
   - Quotex / OTC / Crypto অ্যাসেট সিলেকশন (EUR/USD, GBP/USD, BTC/USDT ইত্যাদি)।
   - অটো ট্রেড অন/অফ সুইচ, ডেমো ব্যালেন্স ($10,450+), উইন রেট এবং রিয়েল-টাইম ট্রেড এক্সিকিউশন হিস্ট্রি লগ।
   - ম্যানুয়াল CALL (UP ⬆) ও PUT (DOWN ⬇) বাটন।

3. **📈 QX Live Signal Board (লাইভ সিগন্যাল ও ভয়েস অ্যালার্ট)**:
   - রিয়েল-টাইম কাউন্টডাউন টাইমার (৩০ সেকেন্ড / ১ মিনিট ক্যান্ডেল)।
   - ৯৬%+ কনফিডেন্স সহ লাইভ CALL / PUT সিগন্যাল।
   - **ভয়েস অ্যালার্ট**: সিগন্যাল আসা মাত্রই সোফিয়া স্বয়ংক্রিয়ভাবে ভয়েসে ঘোষণা দেয়।

4. **📱 Telegram Bot & Mini App Integration**:
   - `telegram_bot.py` দিয়ে সরাসরি টেলিগ্রামে ইনলাইন বাটন ও ওয়েব অ্যাপ হিসেবে চালানো যায়।

---

## 🚀 কীভাবে রান করবেন (How to Run):

### ১. সাধারণ মোড (এক ক্লিকে চালু):
টার্মিনালে বা কমান্ড প্রম্পটে নিচের কমান্ডটি চালান:
```bash
python run_bot.py
```
এটি স্বয়ংক্রিয়ভাবে FastAPI সার্ভার চালু করবে এবং আপনার ব্রাউজারে `http://localhost:8000` এ সম্পূর্ণ অ্যাপটি ওপেন করে দিবে।

### ২. টেলিগ্রাম বট মোড (ঐচ্ছিক):
আপনার টেলিগ্রাম বট টোকেন দিয়ে চালাতে:
```bash
python telegram_bot.py YOUR_BOT_TOKEN
```
